# CoA Builder Static HTML

This repository contains the exported static HTML build for the CoA Builder.

## Run in GitHub Codespaces

1. Open the repository in Codespaces.
2. Run:

   ```bash
   npm start
   ```

3. Open the forwarded port `3000`.

## Publish with GitHub Pages

The included `.nojekyll` file is required so GitHub Pages serves the `_next` assets correctly.
